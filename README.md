# statistics-toolkit
A generic, dataset-independent statistical analysis toolkit built with R Shiny.

## About

Statistics Toolkit is an interactive web-based application designed to make commonly used statistical analyses accessible through a simple graphical interface.

The application is being developed with a focus on:

* Dataset-independent statistical analysis
* Automatic variable-type detection
* Interactive data exploration
* Descriptive statistics
* Data visualization
* Statistical testing
* Regression and correlation analysis
* Advanced statistical procedures

## Current Status

🚧 **Under Development / Testing**

The toolkit is currently being developed and tested. Features, statistical procedures, interface elements, and outputs may change as the project evolves.

## Technology

* R
* Shiny
* ggplot2
* readxl
* haven

## Intended Users

The toolkit is being developed for students, researchers, teachers, and professionals who need to perform statistical analysis without writing statistical code for every procedure.
